# Juicy Couture Coin graphics

The Render web app serves these original JPEG assets from `public/graphics/`:

- `coin-medallion.jpeg` — coin artwork shown in the landing page hero.
- `juicy-banner.jpeg` — branded community banner shown below the hero.

Keep the source JPEGs at the repository root. `npm run build` copies both into `public/graphics/`. The page references them at `/graphics/coin-medallion.jpeg` and `/graphics/juicy-banner.jpeg`.
